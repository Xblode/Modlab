# Instructions agents

Lis d'abord `CLAUDE.md` (règles du projet), puis `.bframe/ETAT.md` (où en est le projet).

- Mémoire du projet (cap, état, décisions, idées, tâches) : `.bframe/` — après une avancée notable, l'orchestrateur **met à jour** `.bframe/ETAT.md` dans le même tour (ligne de sujet + `prochaine_action` si besoin) ; ne pas tenir un second journal d'état dans le chat.
- Documentation : `docs/` (sommaire dans `docs/README.md`) — **ne pas ouvrir ni lire `docs/archive/**`** sauf demande explicite de l'humain.
- Portes d'entrée code : `crates/modlab-core/README.md`, `crates/modlab-game-minecraft/README.md`, `ui/src/shell/README.md`.
