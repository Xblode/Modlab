# Adaptateur Skyrim

Ce dossier porte les règles propres à Skyrim, que le Core ne connaît pas.

## Modules

- `engine` : moteur.
- `fomod` : installateurs FOMOD.
- `graphics` : réglages graphiques.
- `installer` : installation.
- `mo2` : import MO2.
- `usvfs` : déploiement par USVFS.

Référence : `docs/01-architecture-decidee.md` §3.1 et §4.
